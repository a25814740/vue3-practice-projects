# NAMING_CONVENTION.md

## 基本命名規則

- 專案資料夾：`kebab-case`
- 元件：`PascalCase.vue`
- composable：`useSomething.ts`
- store：`something.store.ts`
- route 檔：`routes.ts` 或 `xxx.routes.ts`
- 文件：`UPPER_SNAKE_CASE.md` 或一致的 `kebab-case.md`

## 元件命名原則

- 頁面元件用明確功能命名
- 通用元件用語意命名
- 不要用 `Temp.vue`、`Test.vue` 這類模糊名稱

## 文件命名原則

- 總覽文件用大寫名稱，方便快速辨識
- stage 類文件固定用 `stage-xx.md`
- 答案文件與 stage 編號一一對應
