# LEARNING_PATH.md

## 學習路線總覽

這份路線是按照「像打關卡一樣前進」來設計的。  
建議不要直接跳到困難關卡，否則很容易只是在抄程式，不是真的學會。

## 推薦順序

1. `01-counter-todo-lab`
   - 先完成 Stage 01
   - 再完成 Stage 02
   - 有餘力再做 Stage 03
2. `02-notes-habit-tracker`
   - 建議至少先補完 01 的基礎，再進到 02 與 03
3. `03-mini-admin-dashboard`
   - 建議在前兩個專案完成後再進入
4. `04-project-task-manager`
   - 建議最後做，作為整合型練習

## 建議的前置關係

- `ref` / `reactive` / `computed` / `v-model` → 先從 01 開始
- `watch` / `watchEffect` / composables → 01 後半與 02
- Router / Pinia / CRUD / async API → 03
- 權限概念 / 模組拆分 / 較完整狀態流 → 04

## 卡住時怎麼回頭補

- 卡在狀態處理 → 回讀 `skills/composition-api.md`
- 卡在表單與驗證 → 回讀 `skills/forms-and-validation.md`
- 卡在列表或 CRUD → 回讀 `skills/crud-patterns.md`
- 卡在 API 流程 → 回讀 `skills/async-and-api.md`
- 卡在路由或頁面切換 → 回讀 `skills/vue-router.md`
- 卡在共享狀態 → 回讀 `skills/pinia.md`

## 完成節奏建議

- 每個 stage 先做到可驗收
- 再做可讀性整理
- 最後才做延伸優化
