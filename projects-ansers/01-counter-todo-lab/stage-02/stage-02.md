# Stage 02：Todo 與篩選

## 本階段目標

把輸入、清單與條件篩選串起來，完成最小 Todo 流程。

## 建議實作方式

- 用陣列存 Todo
- 用 `v-model` 處理輸入
- 用 `computed` 做篩選結果

## 關鍵 Vue 3 觀念

- `v-for` 要有穩定 `key`
- `computed` 適合衍生清單
- 空狀態要明確顯示

## 常見錯誤

- 把篩選邏輯寫散
- 新增時忘了清空輸入欄
- 完成與未完成的資料結構不一致

## 參考檔案切分

- `src/App.vue`

## 驗收重點

- 可以新增 Todo
- 可以切換完成狀態
- 可以切換篩選條件

## 可選優化

- 加入刪除
- 加入完成數統計
