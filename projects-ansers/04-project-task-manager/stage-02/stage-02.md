# Stage 02：任務與專案資料流

## 本階段目標

建立專案與任務之間的關聯資料流。

## 建議實作方式

- 先定義關聯資料
- 再做列表與編輯
- 先完成主流程

## 關鍵 Vue 3 觀念

- 關聯資料要有一致來源
- 表單和列表應分責任
- `computed` 很適合整理關聯結果

## 常見錯誤

- 專案與任務互相污染
- 編輯流程過度分散
- 在模板裡寫太多邏輯

## 參考檔案切分

- `src/App.vue`
- `src/views/ProjectsView.vue`
- `src/views/TaskEditorView.vue`

## 驗收重點

- 可以建立與更新
- 列表同步正確
- 關聯清楚

## 可選優化
