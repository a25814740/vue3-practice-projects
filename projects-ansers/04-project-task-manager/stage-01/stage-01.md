# Stage 01：模組與路由骨架

## 本階段目標

先把整體模組邊界與路由骨架定下來。

## 建議實作方式

- 先畫 domain 區塊
- 再切路由
- 先有骨架，再補內容

## 關鍵 Vue 3 觀念

- 先有結構，再談複雜資料流
- 路由應對應使用者任務
- layout 與功能頁面要分開

## 常見錯誤

- 一開始就把頁面做太深
- 模組邊界不清楚
- 路由與功能耦太緊

## 參考檔案切分

- `src/App.vue`
- `src/router/index.ts`

## 驗收重點

- 路由骨架清楚
- 模組分區看得懂
- 後續好擴充

## 可選優化

- 側邊導覽
- 麵包屑
