# projects-ansers

這裡放各子專案的階段答案與參考代碼。
正式專案目錄只保留規格與實作，不再使用 `answer/` 當答案主目錄。

## 標準結構

```text
projects-ansers/
└─ project-name/
   ├─ stage-01/
   │  ├─ stage-01.md
   │  └─ src/
   │     └─ App.vue
   ├─ stage-02/
   │  ├─ stage-02.md
   │  └─ src/
   │     └─ App.vue
   └─ ...
```

## 使用原則

- `stage-xx.md` 放階段說明、驗收條件、常見錯誤
- `src/` 放對應階段的參考代碼
- 階段目錄名稱要和 stage 編號一致
