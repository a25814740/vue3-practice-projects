# Stage 02：CRUD 主流程

## 本階段目標

把列表、詳情、建立、編輯、刪除串成完整流程。

## 建議實作方式

- 先做列表
- 再做表單
- 最後補詳情與刪除

## 關鍵 Vue 3 觀念

- CRUD 要有一致資料來源
- 表單狀態要獨立
- 完成後畫面要同步

## 常見錯誤

- 新增與編輯邏輯混雜
- 刪除後沒刷新
- 詳情頁資料來源不明

## 參考檔案切分

- `src/App.vue`
- `src/views/UserListView.vue`
- `src/views/UserFormView.vue`

## 驗收重點

- CRUD 能跑完
- 清單會同步更新
- 詳情能正確顯示

## 可選優化

- 確認刪除
- 排序與搜尋
