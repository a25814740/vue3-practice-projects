# Stage 04：守衛與權限概念

## 本階段目標

補上簡單登入與路由守衛概念。

## 建議實作方式

- 先定義登入狀態
- 再檢查路由
- 規則保持簡單

## 關鍵 Vue 3 觀念

- 守衛只做入口檢查
- 權限資料集中管理
- 不要把規則散到每頁

## 常見錯誤

- 守衛太複雜
- 權限邏輯亂放
- 沒有未登入導向

## 參考檔案切分

- `src/App.vue`
- `src/router/guards.ts`
- `src/stores/auth.store.ts`

## 驗收重點

- 未登入會擋住
- 已登入可進入
- 規則看得懂

## 可選優化

- 角色判斷
- 登入後回跳
