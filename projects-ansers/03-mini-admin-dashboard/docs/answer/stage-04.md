# Stage 04 答案：守衛與權限概念

## 本階段目標

加入最基本的權限保護概念，讓後台更接近真實場景。

## 建議實作方式

- 先定義登入狀態
- 再用路由守衛檢查
- 權限規則保持簡單

## 關鍵 Vue 3 觀念說明

- 路由守衛適合做入口檢查
- 權限狀態可放 Pinia
- 不要把所有規則都寫進頁面

## 常見錯誤

- 守衛邏輯過度複雜
- 權限判斷散落在各頁
- 沒有未登入時的導向

## 參考檔案切分方式

- `src/router/guards.ts`
- `src/stores/auth.store.ts`
- `src/views/LoginView.vue`

## 驗收重點

- 未登入時不能進受保護頁面
- 已登入可正常進入
- 權限規則易懂

## 可選優化方向

- 加入角色判斷
- 加入登入後回跳
