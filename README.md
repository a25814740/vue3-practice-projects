# Vue 3 練功型專案倉庫

這是一個以 **Vue 3 學習與實作訓練** 為核心的多關卡倉庫。  
重點不是做商業成品，而是把常用能力拆成可逐步完成的小專案，讓人類與 AI Agent 都能照著文件接手。

## 倉庫定位

- 以 Vue 3、Vite、Composition API 為主軸
- 以「先理解，再擴充」為原則
- 以階段式學習與驗收為核心
- 每個子專案都能獨立驗收，不綁在一起

## 內容結構

- `AGENTS.md`：AI Agent 的工作規則與閱讀順序
- `TASK.md`：目前總任務與第一階段目標
- `PROJECT_RULES.md`：開發與命名規範
- `SKILLS.md`：技能總表與前置關係
- `docs/`：總覽、學習路線、架構與進度
- `skills/`：每個技能的教學型操作說明
- `projects/`：各關卡子專案骨架
- `projects-ansers/`：各子專案答案與參考解法

## 推薦閱讀順序

1. `AGENTS.md`
2. `TASK.md`
3. `PROJECT_RULES.md`
4. `SKILLS.md`
5. `docs/LEARNING_PATH.md`
6. `docs/PROJECT_MAP.md`
7. 各子專案的 `docs/STAGE_CHECKLIST.md`

## 目前狀態

第一階段先建立文件、skills 與資料夾骨架，後續再依難度由低到高補實作。
