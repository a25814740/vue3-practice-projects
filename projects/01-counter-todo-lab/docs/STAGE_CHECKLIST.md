# STAGE_CHECKLIST.md

## 專案目標

用最小功能練會 Vue 3 的基礎資料流：狀態、事件、顯示、列表、表單。

## 本專案會學到哪些 Vue 3 能力

- `ref`
- `reactive`
- `computed`
- `v-model`
- 條件渲染
- 清單渲染
- 基本元件拆分

## Stage 01：Counter 基礎

- **目標**：建立最小的 Vue 3 狀態變更流程
- **要完成的功能**：計數器加減、歸零、目前值顯示
- **會碰到的 Vue 3 重點**：`ref`、事件綁定、模板插值
- **驗收條件**：按鈕能正確改變數值，畫面即時更新
- **完成後建議自我檢查項目**：命名是否清楚、狀態是否只有一份、畫面是否容易讀

## Stage 02：Todo 與篩選

- **目標**：把表單與清單渲染串起來
- **要完成的功能**：新增 Todo、切換完成狀態、篩選顯示
- **會碰到的 Vue 3 重點**：`v-model`、`computed`、`v-for`、`v-if`
- **驗收條件**：可以新增、切換、篩選，而且空狀態有顯示
- **完成後建議自我檢查項目**：資料結構是否穩定、篩選邏輯是否集中

## Stage 03：本地儲存與拆分

- **目標**：讓專案能保存資料並開始做基本拆分
- **要完成的功能**：本地儲存、讀取初始化資料、拆出小元件
- **會碰到的 Vue 3 重點**：`watch`、生命週期、props / emits
- **驗收條件**：重新整理後資料仍存在，元件切分合理
- **完成後建議自我檢查項目**：副作用是否集中、資料來源是否清楚
